## BAD-BEHAVIOR RISKS — research-first ticks (VERIFY before fixing; the critic already had one false positive)
- **check-license is a STUB that always returns `{isLicensed:true}`** → zero Marketplace-license enforcement; every gated/destructive feature runs on an unlicensed/expired install. INVESTIGATE: intentional dev-stub or shipped paywall bypass? (Project note: "Runs on Atlassian" is the constraint; licensing may be deliberately deferred.)
- **`enumerate-realm-rulesets` = UNGATED read of every space's `admin-settings-space-*`** → potential cross-space config disclosure. INVESTIGATE: is it reachable from UI / directly via action-router? Does it re-authz?
- **`purge-seal-record` allows "anyone if there is no seal record"** (gated only by global `allowSealPurge`) → a non-owner can permanently trash-then-purge any attachment lacking a seal record. INVESTIGATE: intended?
- **`app-account-id` KVS cache is never invalidated** → if Atlassian rotates the app account id, the loop-guard breaks permanently (revert/version-churn loop OR permanent fail-closed skip). No self-heal. INVESTIGATE robustness.
- **Trigger asymmetry**: `pageContentTrigger` fails CLOSED on unresolved app-account-id but `artifactEventTrigger` PROCEEDS (id-guard no-ops) → under a `/user/current` 401/403/429 an attachment revert could fire against the app's own re-upload and loop. INVESTIGATE whether artifactEventTrigger can self-revert-loop.
- **KVS `query()` eventual consistency is user-visible**: enumerate-* + secondary indexes (space-protection-*, workflow-idx-*) read eventually-consistently → the realm-console counts can disagree with the ribbon/overlay for the consistency window after any seal/transition, with no reconciliation/"refreshing" affordance. RESEARCH: bound the window, decide a UI hint (this is the it30 empty-index transient, generalized).
- **Per-browser localStorage prefs** (overlay columns/sort, explainer-dismissed, panel prefs) are per-device NOT per-user → a second device loses layout + re-sees onboarding. Decide if server round-trip is wanted.
