# Iteration 8 — #44 Enforced Approved state (revert-on-tamper) — the differentiator

Branch: `aql/workflow-state-engine`. The moat: an Approved page can be physically enforced — a non-approver/non-steward edit is reverted (or the page is demoted to Draft). The flagged LOW-confidence pipeline surgery in the repo's most delicate file.

## Design-first (the discipline for this feature)
Before touching `triggers.js`, a design workflow (4 readers → synthesis → 3 adversaries → fixer) produced a vetted spec (`state/F44-DESIGN.md`) that caught 17 gaps in v1 — incl. a phantom `realmKeyFor` (ReferenceError). Root fix: the ANCHOR RULE — `approvedVersion` is set ONLY from the quorum-reviewed version (fail-closed on drift) or an observed post-write/live version; never a pre-pass guess. **DEMOTE is the safe default** (no body write = provably non-destructive); REVERT is per-space opt-in gated behind the harness scenarios.

## Implementation (per the vetted design)
- **Engine (logic.js):** `transitionPageWorkflow` records `enforce`/`approvedVersion`/`approvers` on entering an enforce state (clears on leaving); `fetchLivePageVersion`, forward-only `restampApprovedVersion`, `restampIfEnforced` (seal-create §2.7).
- **Approvals:** `decideApproval` anchors `approvedVersion` to the reviewed `pinnedVersion`, fails CLOSED on null version, and returns `outcome:"stale"` if the page drifted during the approval window (a tamper can't be laundered into the baseline). `stale` read-model wired.
- **Trigger (triggers.js):** `collectWorkflowEnforcementForPage` (cheap probe → privileged / revert / inline-demote); Pass 0 `enforceApprovedStatePass` (whole-body revert to a freshly-re-read baseline, CL-1 empty-guard, CL-7 canonical equality-guard) runs FIRST and sets `ctx.enforcedRevert` → suppresses the seal passes (who-wins + SV-M5 suppression); §2.5 post-write reconciliation re-stamps to the OBSERVED written version; one `writeDocBody`. `workflowSweep` (hourly): cursor-paginated, author-aware (adopts an authorized dropped-event edit), self-healing (null baseline), dedup-guarded, empty-baseline-safe.
- **Steward check:** **a real bug the harness caught** — `isOperatorSteward` → `isOperatorSiteAdmin`/`isOperatorRealmSteward` use `asUser()`, which has NO context inside a trigger/scheduled fn, so a steward editor was mis-classified. Added `isAccountStewardAsApp` (asApp space-ADMINISTER + explicit KVS steward list); used in the probe + sweep.
- **Seals:** `restampIfEnforced` on seal/section-seal creation keeps the approved baseline seal-complete (Defect 2), so the blanket seal-pass suppression can't strip a post-approval seal.
- **Manifest/boot:** +`workflow-sweep-fn` + hourly `workflow-sweep-scheduled` (minor version, no new scope). **UI:** enforce-mode select in the Workflow tab ("If an Approved page is edited by a non-approver" → Move to Draft / Revert) + empty-approver warning.

## Verify (live)
- **Full grade PASS** — all 9 E2E suites, incl. **workflow-enforce-e2e 18/18** AND the existing seal/section content-protection E2Es (live-trigger 8/8, seal 4/4) — proving the heavy `pageContentTrigger` surgery did NOT break content protection (the critical no-regression gate).
- enforce-e2e proves: enforce capture + clear on leave; who-wins DECISION via synthetic actors (non-approver→revert; snapshot∩live approver→privileged; steward→privileged; revoked approver→not privileged; empty-approver+revert→downgraded to demote); revert MECHANISM reverts the body to the approved version + re-stamps forward; **CL-1 empty baseline never blanks the page**; demote drops to Draft; sweep self-heals a null baseline; sweep adopts an authorized (steward-authored) drift instead of reverting.
- **Harness constraint (flagged honestly):** the harness user is a site admin (steward), so a *real* non-privileged edit → end-to-end revert can't be driven directly; the decision + revert mechanism are proven via dev-hook seams with synthetic actors, and the steward path via the KVS steward list. Two harness flakes under full-suite WFH concurrency (write-timing) fixed with retry/poll.
- **Adversarial 4-lens review found 8 real defects the green harness MISSED** — all fixed, re-graded PASS:
  1. **[HIGH] Tamper-laundering** — I dropped the design's `restampObservedFrom="equal"` discriminator, so §2.5 advanced `approvedVersion` to the tampered live version on ANY no-write path (CL-1 abort, `readDocBodyAtVersion` throw, all-409). Fix: `ctx.enforceObservedEqual` set ONLY on confirmed equality; §2.5 revert-restamp gated on it → an aborted revert leaves the baseline at V0 (fail-closed; sweep retries). Regression guard added (Scenario E asserts no-advance).
  2. **[MED] Steward check** missed adminGroups + site/org-admin — `isAccountStewardAsApp` now also does an asApp `expand=groups,operations` check.
  3. **[MED] Group-approver failure masked as `[]`** — `fetchGroupMembers` now returns `{ids, ok}`; `resolveApproverIds` sets `unresolved`; the probe/sweep trust the snapshot approver during a group-service outage (revocation only honored when expansion succeeds).
  4. **[MED] `restampApprovedVersion` lost-update** — re-reads fresh before persist + aborts if the record left enforce/changed state (shrinks the clobber window; KVS has no CAS).
  5. **[LOW] Sweep revert** now has the same CL-7 equality short-circuit (no needless destructive write).
  6. **[MED] TOCTOU** — `highestSanctionedVersion` walks intervening versions; the revert adopts the highest privileged-authored version in (av, cur) instead of destroying a concurrent approver edit.
  7. **[LOW] Demote-edge** — defensive log when a (hypothetical custom) workflow lacks the Approved→Draft edge; default workflow unaffected.
  Rejected: 1 (a claimed "panel-retained but body-lost baseline" — the capture paths can't produce it).
