Decisions the mockups embody — say which to change

1. Level colours are fixed and solid (green / blue / amber / red) and identical in both themes; native levels bring their own colour from Confluence and are used as-is.
2. The ribbon is 44px tall inside the 48px cap, with 2px margin; nothing wraps, nothing stacks. Popovers are gone: everything deeper lives in the modal.
3. “Exceptions only” opens for three triggers only (threshold, waiting-on-you, active alert). “Locked by … · Request edit” for a collaborator counts as waiting-on-you.
4. The chip’s counter is the viewer’s waiting-on-you count for this page; the ribbon’s pill repeats it. My work carries the cross-space total.
5. One primary action per seal row, by state: Seal · Request edit · Waiting for {owner} · Edit now until {time} · Release. Extend, Watch, Copy link and Force release (space admins, typed reason) sit under ⋯.
6. Copy uses the renamed vocabulary throughout: space, space admin, user, group, attachment, seal.
