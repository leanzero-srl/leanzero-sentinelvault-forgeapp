# Sentinel Vault — UX review against the Atlassian Design System (2026-09-14)

Read-only review of every user-facing surface. Scope: `src/ui/surfaces/{inline-panel,overlay,doc-ribbon,section-setup,panel-setup,my-work,realm-console,steward-console}/index.jsx`, `src/ui/tokens/*.css`, `src/ui/kit/*.jsx`, the outbound copy in `src/server/infra/{notice-blueprints,notice-composer,approval-blueprints,validation-blueprints,outbound-notify}.js`, `src/server/triggers.js`, `README.md`, `manifest.yml`.

Owner's non-negotiable UI rules applied throughout: no left accent rails, no faded/washed tints (solid saturated colours), no native select/alert/confirm, distinctive not template-y.

**Caveat on line numbers.** The working tree was being edited by another session while this review ran (`git status` shows ~20 modified files plus the untracked classification capsule and `ClassificationTab.jsx`). Line numbers are from the final pass of each file; re-run the grep commands in §1.4 before editing.

**Effort key:** S = under half a day, M = 1–3 days, L = a week or more. Effort is given for blast-radius awareness only; the list is ordered by user-visible payoff and correctness risk, never by size. **Confidence** = how sure I am the fix is straightforward and will not regress something.
